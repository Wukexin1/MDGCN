Release preparation status — 25 October 2026

Repository: https://github.com/Wukexin1/MDGCN.
Private during preparation, with a public release planned. Archive download

Records and checkpoints
-----------------------
All 471 configurations, histories and saved predictions are retained.
Independent local checks verified all 471 selected checkpoints against the
historical run hashes: 363 complete, 36 uniform and 72 components. The component
checkpoints cover 36 runs at batch size 25 and 36 at batch size 32. All returned
archives passed integrity checks, with no duplicate or extra checkpoints.
The prepared release has four independent checkpoint ZIPs. Four selected
historical models have also completed the CPU checks below.

Completed checks
----------------
The statistics verifier found no discrepancies in 471 runs, 75,630 prediction
rows, 630 displayed mean/standard-deviation pairs and 30 candidate statistics.
Figures 4 and 6 can be regenerated with tools/plot_figures.py.
All 471 input checks passed for their compact inputs; 60 complete-suite runs
also require the separately stored geodesic cache.

Small CPU fixtures check all three evaluator paths and error handling.
Four actual historical models were also evaluated: synthetic PointNet,
synthetic MDGCN1, real-data MDGCN2, and a real-data component model with soft
aggregation and add fusion at batch size 25. All use coordinates and seed 24.
All 176 test predictions agree in category with the saved results. Probabilities
are not bitwise identical. Reports record the local CPU environment and times;
these checks are not a rerun of all 471 models or a GPU timing measurement.

Runtime records
---------------
The retained logs cover 471 runs and 117,750 epochs. Recorded intervals sum to
49.57 hours for complete, 6.55 hours for uniform and 21.94 hours for components.
The timer boundaries differ between suites; see docs/ENVIRONMENT.md.
The full saved-result statistics check took 2.62 seconds on the local CPU.

Environment
-----------
Two current server snapshots were received. Their hardware and software fields
are identical, with different collection times. The kernel is 5.15.0-198-generic;
training records show 5.15.0-187-generic. The current snapshots are retained in
environment/ and summarized in docs/ENVIRONMENT.md.
